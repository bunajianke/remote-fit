# Remote Fit

免费使用的 Windows / macOS 远程操作辅助工具，让手机和平板操作电脑更顺手。配合你已有的远程软件使用。

- 按手机、折叠屏和平板模板计算目标尺寸，选择系统或驱动支持的显示模式。
- 远程会话开始时切换，结束时还原；提供手动会话入口。
- 悬浮工具条提供复制、粘贴、Enter、最小化与全屏等快捷操作。
- Windows 支持四边停靠和自由拖动；Mac 工具条固定右侧，可收起为悬浮按钮。支持浅色／深色／跟随系统及窄屏导航。
- 软件内检查更新，保留设置，远程会话期间推迟安装。

## 下载

Windows：前往 [Windows 0.3.0 下载页](https://github.com/bunajianke/remote-fit/releases/tag/v0.3.0)，选择对应架构的 **Setup.exe**，便携使用请选择完整的 **Portable.zip**。

Mac：前往 [macOS 0.1.17 下载页](https://github.com/bunajianke/remote-fit/releases/tag/mac-v0.1.17)，下载 **RemoteFit-mac-universal.dmg**，将应用拖入“应用程序”。现有版本也可在软件内检查更新。

Mac 0.1.17 将工具条与其他窗口的避让间距从 8 点缩小到 2 点，减少低分辨率下的空隙。自动避让与最大化使用相同间距，收起或隐藏后释放预留区域。

Mac 0.1.16 修复悬浮按钮轮廓，使用独立正圆和对称阴影。工具条固定右侧，位置选项暂时隐藏；收起按钮固定在设置按钮附近，不支持拖动。收起时释放窗口避让区域，展开后再预留。

Mac 0.1.15 增加工具条收起功能：点击“收起”变为圆形悬浮按钮，再点展开，自动记住收起状态。自由模式可拖动悬浮按钮；收起时恢复自动避让的窗口，展开后重新预留区域。同步优化图标和文字留白、设置上方分割线，沿用固定测试签名身份。

Mac 0.1.14 固定自签名测试证书，后续版本沿用同一签名身份，避免临时签名随构建变化而使旧授权失效。从 0.1.13 或更早版本升级后，仍需自行刷新一次辅助功能授权。自签名测试证书不等同于 Developer ID 签名或苹果公证。

Mac 0.1.13 改用不激活应用的原生工具栏按钮，保留原操作目标；作为菜单栏工具运行，避免 Command+Tab 切回 Remote Fit。提示气泡锚定触发按钮。设置仍可从工具条或菜单栏打开。

Mac 0.1.12 修复“上一个桌面”图标空白，前后桌面使用成对的左右箭头图标。

Mac 0.1.11 修复前后桌面切换无响应，改进最大化／还原和窗口居中的兼容处理。窗口调整等待真实位置和尺寸生效后再记录还原状态，受限窗口失败时尝试恢复原位置。已实测工具条点击、Chrome 最大化与还原、真实桌面往返切换。窗口操作及系统快捷键需要辅助功能权限。

Windows 10/11，x64 或 ARM64。Mac 需要 macOS 14 或更新版本，支持 Apple 芯片与 Intel。

旧版尚无在线更新器，需要手动安装新版一次。Windows 更新器依赖完整安装结构，不能只拷贝单个 EXE。配置与显示恢复记录保存在用户目录，升级保留现有设置。Mac 不要从只读 DMG 中直接运行，否则不能就地更新。

当前安装包尚未取得 Windows 代码签名或 Apple Developer ID 公证，首次启动请按系统提示核对来源。每个包提供 SHA-256 校验；Mac 在线更新包与更新信息另有 Ed25519 签名。

## 当前兼容范围

Mac 已接入 UU 被控会话检测；向日葵、ToDesk 自动检测仍待适配。Windows 内置 RDP/WTS 检测，第三方远控目前使用手动会话、日志或回调接入。无法识别的远控软件可使用手动会话。

仅使用系统或驱动提供的显示模式；Windows 可尝试驱动接受的自定义模式。没有创建任意尺寸虚拟屏的功能。Mac 版仍处于测试阶段。

此公开仓库仅分发安装包和更新信息，应用源码保存在私有仓库。
